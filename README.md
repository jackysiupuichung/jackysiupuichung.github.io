# jackysiupuichung.github.io

Personal homepage of Jacky Siu Pui Chung, served by GitHub Pages as a static site (no build step).

- `index.html`: the whole site; publication pages are `#pub-…` views rendered from the `PUBS` object in its script
- `profile.jpg`, `slides/`, `posters/`: files linked from the page
- `.nojekyll`: tells GitHub Pages to serve the files as they are

Preview locally with `python3 -m http.server 8000` and open http://localhost:8000.

The previous Jekyll (academicpages) site is kept on the `jekyll-archive` branch.
